Quick Guide — How to Use Test Suites

1

Create a Suite

Click "New Suite" to create a test suite (e.g. Regression Suite, Smoke Suite). Suites group your test sections & cases.

2

Add Sections

Select a suite, then click "+ Section" to organize tests into folders (e.g. Login, Settings). You can also add sub-sections using the folder icon on hover.

3

Add Test Cases

Hover over a section and click the "+" icon to add a test case. Fill in the title, steps, expected result, priority & type.

4

View & Edit Cases

Click any test case to open its detail view. Admins can click "Edit" to update title, steps, priority, assignee, and more.

Tip: Expand sections by clicking them. The hierarchy is Project → Suite → Section → Test Case. After creating cases here, go to Test Runs to create execution runs and track pass/fail results.
